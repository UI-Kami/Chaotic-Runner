# 🏃‍♂️💨 Chaotic Runner

> *"MAY CHAOS TAKE THE WORLD!"*

Welcome to **Chaotic Runner**, an endless, adrenaline-fueled, Subway Surfer-style running game set against the neon backdrop of a sprawling night city. 

The goal is simple: survive. The execution is... well, absolute chaos. Dodge oncoming traffic, slide under barriers, leap over hazards with funky animations, and pray you don't get obliterated by a localized meteor shower that knows exactly where you're going.

## 🎮 Controls
* **[S] or [Down Arrow]:** Slide
* **[A] / [D] or [Left/Right Arrows]:** Switch Lanes
* **[Spacebar]:** Jump
